# Проверка установки

Отмечайте отдельно: установлен → обнаружен Codex → выполнен реальный сценарий.
Не отмечайте весь стек рабочим по одной команде doctor.

| Компонент | Минимальная проверка | Что считать успехом |
|---|---|---|
| AGENTS.md | Новый сеанс читает разделы и реальные пути | Нет незаменённых placeholders, старые правила сохранены |
| PROJECTS.md | Сравнение checksum до и после настройки | Существующий реестр не изменился |
| Context7 | resolve-library-id и query-docs | Получен содержательный ответ с источником |
| Impeccable | Skill виден, читается SKILL.md; затем узкая UI-задача в demo | Нет ошибок загрузки; для hooks отдельно проверено доверие и срабатывание |
| Emil | Видно emil-design-eng; разбор небольшого UI-фрагмента | Агент читает skill и даёт конкретные рекомендации |

| GSD | gsd-help и тестовый план в отдельной папке | Команды доступны, артефакты создаются; делегирование проверяется отдельно |

| Agentation UI | Браузерная аннотация → чтение MCP | Совпадают текст, элемент и проект |
| MTGA, если выбран | status, on/off на тестовой копии | Переключается только блок стиля |

## Что проверено для публикации этой сборки

10 сентября 2026: Context7 в существующем окружении выполнил resolve и query;
наличие Impeccable и emil-design-eng подтверждено чтением установленных skills.
Установочные команды сверены с upstream README/CLI и официальными docs.
Локальный валидатор проверяет структуру, ссылки на файлы, TOML и признаки
случайно добавленных приватных данных. Это не замена полноценному secret scanner.

**Чистая установка полного стека на новом компьютере не выполнена в рамках
публикации репозитория.** Предыдущие проверки отдельных инструментов на машине
автора не доказывают совместимость любой будущей версии и ОС.

## Типичные проблемы

- MCP есть в TOML, но нет tools: новая задача, проверка запуска сервера,
  авторизации, stderr и доступности исполняемого файла.
- Context7 возвращает 401: проверьте вход или наличие переменной в процессе Codex,
  не печатая её значение. При 429 дождитесь снятия ограничения.
- CLI работает в терминале, но не в desktop: проверьте PATH; используйте абсолютный
  путь к установленному бинарю в локальном конфиге.
- Agentation doctor жалуется на Claude: проверяйте фактический Codex MCP, а не
  только диагностику другого клиента. Сетевой sandbox может мешать health-check.
- Порт 4747 занят: выясните, какой процесс слушает, прежде чем запускать второй.
  Не останавливайте неизвестный процесс. При смене порта синхронизируйте endpoint.
- Skill продублирован: сравните источники ~/.agents/skills и ~/.codex/skills;
  сохраните одну актуальную установку, удаление согласуйте.
- Hooks не выполняются: поддержка события, путь, разрешения и trust проверяются
  отдельно. Наличие файла hooks.json недостаточно.

## Проверка самого репозитория

```bash
python3 scripts/validate.py
git diff --check
```

Перед push просмотрите staged diff и список файлов. Реальные config.toml,
PROJECTS.md, backup и Wiki остаются локально.
