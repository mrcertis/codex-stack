# Мои проекты

Приватный локальный реестр. Скопируйте в ~/.claude/PROJECTS.md (Claude Code) или
~/.codex/PROJECTS.md (Codex) только если файла ещё нет. Не коммитьте заполненную копию. Ни одна запись не разрешает изменения.

| Проект | Локальный путь | Назначение | Wiki-space | Проверка состояния |
|---|---|---|---|---|
| example-app | /absolute/path/to/example-app | Краткое описание | example-app | Прочитать AGENTS.md, README и git status |

По умолчанию доступ только на чтение. Пароли, токены и ключи здесь не хранить.
