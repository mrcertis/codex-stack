# Хуки Codex Stack

Это собственные небольшие обработчики для Codex, а не экспорт личных hooks автора.
Исходник: [stack-context.py](../hooks/stack-context.py).

| Событие | Результат |
|---|---|
| SessionStart | `hookSpecificOutput.additionalContext`: маршрут нового проекта, AGENTS и Wiki |
| UserPromptSubmit | То же напоминание, в том числе на следующем запросе после compact |
| PostCompact | `systemMessage`: уведомление в интерфейсе/журнале, не обещание контекста модели |

Хук читает имя события и проверяет наличие установленного stack-start. Не сохраняет
prompt или transcript, не читает проекты и секреты, не запускает команды, не пишет
в Wiki и не обращается в сеть. При запросе на новый проект он направляет агента
к stack-start; агент подготавливает локальный набор, включая Impeccable, **до**
интервью и выбора UI. Подробности — [NEW-PROJECT.md](NEW-PROJECT.md).
Схема: [официальные hooks Codex](https://learn.chatgpt.com/docs/hooks).

## Установка

Из корня checkout:

```bash
python3 scripts/install_config.py
python3 scripts/install_config.py --apply
```

Без `--apply` — только план. Доступны `--codex-home`, `--tools-root`, `--wiki-root`;
пути с пробелами заключайте в кавычки. Скрипт:

- сохраняет прежние изменяемые файлы в приватном `CODEX_HOME/stack-backups/`;
- полностью заменяет AGENTS.md настроенным публичным шаблоном;
- размещает обработчик в `CODEX_HOME/hooks/codex-stack/`;
- устанавливает автоматически выбираемый stack-start в `CODEX_HOME/skills/`;
- добавляет свои записи в hooks.json, сохраняя остальные события и обработчики;
- не меняет config.toml, PROJECTS.md, авторизацию и trust.

Повторный запуск тем же Python не дублирует обработчики. При смене интерпретатора
проверьте старую команду вручную: установщик не удаляет похожие чужие команды.
Некорректный JSON, symlink на пути назначения и AGENTS.override.md останавливают
установку до записи. Резервные копии не должны попадать в публичный checkout.

## Доверие и проверка

Откройте Settings → Hooks или `/hooks` в поддерживаемом Codex. Прочитайте команды
и подтвердите доверие через интерфейс. Создайте новую задачу: проверьте события
SessionStart и UserPromptSubmit в журнале hooks. После compact проверьте уведомление,
а на следующем пользовательском запросе — восстановленное напоминание.

Локальный smoke-test обработчика:

```bash
printf '%s' '{"hook_event_name":"SessionStart"}' | python3 hooks/stack-context.py
```

Это проверяет JSON-контракт, но не исполнение внутри Codex. Если версия не
поддерживает событие или hook остаётся untrusted, так и укажите в отчёте.

Дополнительно обязателен [Z.A.E.B.A.L.](ZAEBAL.md). При подготовке нового проекта
установщик Impeccable добавляет его локальные hooks; их исполнение и trust
проверяются отдельно. Они не включены в исходник stack-context.py.

## Откат

Сначала отключите только команды `hooks/codex-stack/stack-context.py` через
управление hooks. В приватной резервной копии manifest.json перечислены прежние
файлы. Восстановите AGENTS.md при необходимости. Для hooks.json восстановите только
свои записи, сохранив изменения других установщиков, сделанные после backup.
Установка пишет файлы атомарно по отдельности; при сбое диска между файлами
восстановитесь по manifest либо повторите установку после устранения ошибки.
