# Коротко: как работать

Только установили стек? Сначала [завершите настройку подключений](AFTER-INSTALL.md).
Обновляетесь со старой версии? [UPGRADE.md](UPGRADE.md).

## Как начать задачу

Вся разработка идёт через GSD. Команды в Codex пишутся через `$`, в Claude Code —
через `/`. Помнить их все не нужно: достаточно `gsd-next`, остальное он предложит сам.

| Ситуация | Что написать |
|---|---|
| Не знаю, с чего начать / продолжить работу | `$gsd-next` |
| Новый проект с нуля | «Давай сделаем сайт для [название]» или `$gsd-new-project` |
| Уже есть код, но без GSD (нет папки `.planning/`) | `$gsd-onboard` |
| Новая задача в проекте на GSD, своими словами | `$gsd-progress` и описание задачи |
| Небольшая правка | `$gsd-quick --discuss` и что поправить |
| Что-то сломалось | `$gsd-debug` и описание ошибки |
| Проверить сделанное | `$gsd-verify-work` |
| Список всех команд | `$gsd-help` |

Как идёт работа: GSD задаёт вопросы → агент показывает, как понял задачу →
вы отвечаете «ок» → план → «ок» → выполнение → отчёт о сделанном и проверенном →
«ок» → приёмка → «ок» → следующая фаза. В каждой из четырёх точек агент пишет
обычным языком: как понял, что сделает, чего не делает, как проверим, открытые
вопросы. Без вашего явного «ок» он дальше не идёт; молчание согласием не считается.

Если агент сам предлагает команду GSD, он коротко объясняет, что она сделает.
Режимы `gsd-autonomous`, `--auto` и `--all` включаются только по вашей просьбе.

## Обычные просьбы

| Задача | Пример запроса |
|---|---|
| Дизайн | «Страница выглядит скучно, давай переделаем» |
| Взаимодействие | «Это окно открывается слишком резко» |
| Замечания на странице | «Я оставил замечания, поправь» |
| Разобраться в коде | «Как здесь устроена авторизация?» |
| Исследование | «Посмотри, как это делают конкуренты» |
| Проекты | «Что сейчас с этим проектом?» |
| Wiki | «Сохрани это решение в нашей Wiki» |

Это примеры обычной речи, не обязательные формулировки. Агент сам выбирает skills.

## Дизайн

Если подключён Refero, агент сначала ищет в нём образцы реальных экранов и стилей
и показывает их вам; направление выбираете вместе. Без Refero весь процесс ведёт
Impeccable. Вопросы о виде агент задаёт с картинками «как сейчас» и «как будет»
или со ссылкой на образец.

## Стиль и режимы

- MTGA (стиль ответов) включён по умолчанию. Выключить: `$mtga off` в Codex,
  `/mtga:off` в Claude Code. Код, документы и коммиты он не меняет.
- Ponytail работает сам через хуки: агент пишет минимум нового кода. Режим:
  `/ponytail lite|full|ultra|off`.
- [Z.A.E.B.A.L.](ZAEBAL.md) — обязательная часть стека; при срабатывании агент
  следует уровню протокола и проверяет ложный сигнал.

Если инструмент не появился, начните новую задачу, проверьте путь установки и
его ошибки. Не повторяйте установку вслепую. Проверки — в [VERIFY.md](VERIFY.md).
