# Проверка перед публикацией

10 сентября 2026, проверка собственного публичного дистрибутива на случайную
публикацию секретов (CWE-798/CWE-200).

Первоначально опубликованная история проверена Gitleaks 8.30.1 и
TruffleHog 3.97.4: находок нет. Дополнительно выполнено точное сравнение
чувствительных значений из использованной конфигурации со всеми опубликованными
Git blobs, без вывода самих значений: совпадений нет.

14 октября 2026, перед публикацией обновления (GSD вместо gstack): Gitleaks 8.30.1
и TruffleHog 3.99.2 проверили всю историю (9 коммитов) и рабочую копию с
неопубликованными изменениями — находок нет. Сканеры работали без отправки данных
и без онлайн-проверки найденного.

Сканеры запускаются перед крупными обновлениями; регулярный барьер при каждой
правке — scripts/validate.py. Команды:

```bash
gitleaks git . --redact
gitleaks dir . --redact
trufflehog git file://. --no-verification --no-update
trufflehog filesystem . --no-verification --no-update
```

Перед push проверяются рабочая копия и вся история всех веток. После push сверяются remote HEAD и опубликованная история. Сканеры
работают без онлайн-проверки найденных credentials. Бинарные release-артефакты
получены из официальных репозиториев, SHA-256 сверены с их release checksums.

В публикацию допускаются только явно перечисленные в scripts/validate.py файлы.
Личные config.toml, PROJECTS.md, Wiki, backup, состояния плагинов и сырые отчёты
сканеров не входят в дистрибутив. Валидатор — дополнительный барьер, не замена
двум сканерам и просмотру staged diff.

Нулевой результат не является абсолютной гарантией отсутствия любых секретов.
Проверка не распространяется на компьютеры будущих пользователей, содержимое
сторонних установщиков и их последующие версии.
