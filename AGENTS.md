# Работа над этим репозиторием

Это публичная документация Codex Stack. Не устанавливай стек только из-за открытия этой папки. Для установки по запросу пользователя читай docs/AGENT-SETUP.md.

- global-config/AGENTS.md — распространяемый шаблон; корневой AGENTS.md — правила работы над репозиторием.
- Не добавляй реальные PROJECTS.md, config.toml, ключи, дампы окружения, историю задач, личную Wiki или резервные копии.
- Ссылки и команды проверяй по первоисточникам. Не объявляй установленное протестированным без реального вызова.
- Не копируй сторонние skills целиком: используй ссылки и штатные установщики, сохраняй авторство.
- После правок запусти `python3 scripts/validate.py` и `git diff --check`.
- Обновляй каталог, полную инструкцию, короткий старт и шаблоны согласованно.
