# Что изменилось

## 14 октября 2026

Обновление по опыту работы автора. Как перейти со старой версии — [UPGRADE.md](docs/UPGRADE.md).

**Процесс**
- Вся разработка идёт через GSD. Единый вход — `gsd-next`; новый проект —
  `gsd-new-project`, существующий код — `gsd-onboard`, мелкая правка —
  `gsd-quick --discuss`, ошибка — `gsd-debug`. [Как начинать задачу](docs/USAGE.md).
- Четыре точки подтверждения: после интервью, плана, выполнения и приёмки агент
  пишет обычным языком «как понял / что сделаю / чего не делаю / как проверим»
  и ждёт явного «ок». Проектные файлы это правило не отменяют.
- Скорость GSD: тяжёлые проверки — один раз в конце плана, после задачи — быстрые
  тесты; матрица экранов — в конце фазы; без повторной проверки после точечной
  правки плана; короткая модель угроз; планы до 5 задач — в самой сессии
  (`~/.gsd/defaults.json`). Проверяется столько же, но реже.
- Вопросы: уже решённое не переспрашивается; вопросы о виде — на обсуждении фазы
  и с картинками. Для шаблонов и дизайн-систем — сначала макеты всех блоков, потом код.
- stack-start стал тонким: ставит Impeccable и передаёт работу в `gsd-new-project`.
  grill-with-docs больше не ставится в каждый проект.

**Удалено: gstack.** Его заменил GSD. gstack занимал много места на диске
и добавлял объёмные разделы в AGENTS.md и CLAUDE.md, раздувая контекст каждой
сессии. Удаление — [UPGRADE.md, шаг 2](docs/UPGRADE.md#2-удаление-gstack).

**Пути вне iCloud.** Tools и Wiki по умолчанию — `~/tools` и `~/Knowledge`.
iCloud синхронизирует `~/Documents` и `~/Desktop`, создаёт конфликтные копии
«… 2.md», ломающие Wiki, и выгружает файлы в облако. Установщик использует новые пути.

**Codex и Claude Code.** Шаблон AGENTS.md общий для обеих сред; Claude Code читает
его через строку `@~/.codex/AGENTS.md` в CLAUDE.md (`install_config.py --claude-home`).

**Инструменты**
- Ponytail 5.2.0 в Codex и Claude Code, одна версия; работает через хуки.
- MTGA включён по умолчанию; установщик сохраняет его блок при замене AGENTS.md.
- Refero рекомендуется для дизайна (образцы реальных экранов), но не обязателен:
  живой поиск требует платного тарифа, без него всё делает Impeccable.
